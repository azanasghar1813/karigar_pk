# Universal Rule: No Git Commands

The assistant is strictly prohibited from running any `git` command in the terminal or workspace.
This includes:
- `git add`
- `git commit`
- `git push`
- `git pull`
- `git status`
- `git checkout`
- `git branch`
- `git reset`
- `git rebase`
- `git stash`
- Any other git-related command

All git commands and version control operations are exclusively reserved for the user to run manually.
